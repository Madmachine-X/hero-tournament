# 천하제일 영웅대회 (Hero Tournament)

저승에서 열린 "천하제일 영웅대회". 이름 없는 혼 하나가 한국의 역사 영웅들을 모아 한반도 여섯 도시를 차지해 나가는 **한국풍 다크판타지 전략 RPG 프로토타입**입니다.

- 전투: 고전 게임 「퍼스트퀸 4」 방식의 실시간 다수 전투 (영웅 + 혼불 병사)
- 국가 운영: 「삼국지」 방식의 도시 내정, 장수 배치, 출병
- 탐험: 시간대·동료·아이템 조건이 걸린 숨겨진 장소와 영웅 영입 이벤트

> 현재 상태: **1막 「고향의 혼」 플레이 가능한 프로토타입** (태초 국가 한국, 도시 6곳, 이름난 영웅 13명)

---

## 실행 방법

### 1. 그냥 플레이하기 (설치 필요 없음)

`index.html` 파일을 크롬, 엣지, 사파리 같은 브라우저로 열면 바로 실행됩니다. 인터넷이 없어도 돌아가며, 글꼴만 온라인일 때 더 예쁘게 나옵니다.

- 진행 상황은 브라우저에 자동 저장됩니다 (localStorage, 키 `chyw-save-v1`). 타이틀 화면의 **이어하기**로 계속할 수 있습니다.
- 휴대폰 화면에서도 동작합니다.

### 2. 코드를 고친 뒤 다시 만들기 (빌드)

게임은 `src/` 폴더의 파일들을 하나의 HTML로 합쳐서 만듭니다. Python 3만 있으면 됩니다.

```bash
python3 build.py
```

실행하면 두 파일이 새로 만들어집니다.

| 파일 | 용도 |
|---|---|
| `index.html` | 브라우저에서 바로 여는 완전한 문서 (로컬 실행·테스트용) |
| `cheonha.html` | Claude 아티팩트 게시용 (문서 껍데기 없이 본문만) |

### 3. 자동 테스트 (선택)

헤드리스 브라우저로 튜토리얼부터 전 도시 공략까지 자동으로 돌려 보는 스크립트가 `test/`에 있습니다. Node.js와 Playwright가 필요합니다.

```bash
npm install playwright
npx playwright install chromium     # 또는 CHROME_PATH 환경 변수로 크롬 경로 지정
python3 build.py
node test/run7.js    # 캠페인 전체 시뮬레이션 (도시 공략, 주둔, 방어)
node test/run8.js    # 오전/오후/야간, 비밀 장터, 야간 기습
```

스크린샷은 `/tmp/claude-0/shots7`, `/tmp/claude-0/shots8`에 저장됩니다. `run.js`~`run6.js`는 이전 버전용 기록이라 최신 구조와 맞지 않을 수 있습니다.

```

│  ├─ style.css      전체 스타일 (다크 테마, 모바일 대응)
│  ├─ data.js        게임 데이터: 시간대, 세력, 영웅 13명, 기술, 아이템, 도시, 숨겨진 장소, 내정 명령, 진형
│  ├─ game.js        게임 상태와 규칙: 새 게임, 장수 생성, 경제, 내정 명령, 소문 탐색, 적 병력 계산
│  ├─ story.js       대화 시스템, 스토리 대본, 보스 대사, 숨겨진 이벤트 11개
│  ├─ sprites.js     영웅 캐릭터와 혼불 병사를 코드로 그리는 스프라이트
│  ├─ battle.js      실시간 전투 엔진 (부대, 사기, 진형, 상성, 측면 공격, 화살, 미니맵, 자동 전투)
│  ├─ map.js         한반도 전략 지도 (세력 영역, 시간대 색감, 숨겨진 장소 표시)
│  └─ main.js        화면과 흐름: 패널 UI, 출병, 점령, 주둔 선택, 턴 진행, 적 침공, 장터, 비밀 장터
└─ test/             Playwright 자동 테스트 스크립트
```

## 게임 시스템 요약

### 하루의 흐름: 오전 → 오후 → 야간
- **오전·오후 (내정 시간):** 개간, 상업, 성벽, 선정, 징병, 훈련, 인재 탐색, 수송, 장터, 출병
- **야간:** 내정은 불가. 휴식(체력 전부 회복), 소문 탐색, 야간 기습, 이동
- 매일 오전이 시작될 때 상업에서 금, 농업에서 군량이 들어오고 병사들이 군량을 먹습니다.
- 영웅은 시간대마다 한 번씩 행동합니다.

### 도시와 장수
- 장수는 각자 특정 도시에 **주둔**하며, 그 도시의 내정과 출병만 맡을 수 있습니다. 도시마다 2~3명을 권장합니다.
- 장수 확보: 인재 탐색(무명 문관·무관), 점령한 도시의 투항 관리, 숨겨진 이벤트로 역사 영웅 영입, 보스 등용
- 도시를 점령하면 남길 장수를 고르고, 나머지는 출발한 도시로 돌아갑니다.
- 도시별 **위임**을 켜 두면 남는 장수가 알아서 내정합니다.
- 적 세력도 매일 병력을 모으고, 오후나 야간에 아군 도시를 침공합니다.

### 전투
- 영웅 한 명당 혼불 병사 20명, 한 번에 최대 영웅 10명까지 출전합니다.
- **사기:** 영웅의 통솔력을 따릅니다. 영웅이 쓰러져도 사기가 버티면 혼불 대장이 지휘를 잇고, 꺾이면 부대가 도망칩니다.
- **진형 4종:** 학익진(측면 강화), 어린진(초반 돌파), 방원진(방어·사기 유지), 장사진(기동·활)
- **병종 상성:** 보병 > 기병 > 궁병. 측면이나 배후를 치면 피해가 커지고 적 사기가 떨어집니다.
- 적도 장수 한 명당 20명에 혼불 대장 부대가 최대 2개 더해지고, 나머지는 성 안 예비 병력으로 남습니다.
- **야간 기습:** 적 사기 -20, 성벽 효과 절반, 적 지원 부대 없음, 처음 10초는 적이 허둥댑니다.
- 1×/2×/3× 속도, 자동 전투, 휠 확대·축소, 미니맵 클릭 이동
- **결판 내기:** 남은 전투를 자동으로 빠르게 끝내고 결과만 봅니다.
- **연출:** 첫 격돌 순간 멈춤과 흔들림, 영웅 기술 컷인(아군은 짧은 띠, 보스·고유 무기 특수기는 큰 띠), 기술·영웅 격파 때 카메라가 당겨짐
- **소리:** 음원 파일 없이 Web Audio로 만든 칼 소리, 화살, 기술 굉음, 징, 출진 북, 깔리는 전투 북(위기일수록 빨라짐), 승패 음악. `M` 키나 "소리" 버튼으로 끄고 켭니다.

### 영웅과 장비
- 이름난 영웅 13명: 고유 능력치, 고유 기술, 고유 무기가 있습니다. 고유 무기를 장착하면 숨겨진 특수기가 열립니다 (예: 이순신 거북선).
- 장비 칸: 무기 2(쌍무기, 검과 방패, 양손무기), 갑옷 1, 장신구 4

### 도깨비 비밀 장터 (야간 이벤트)
- 밤마다 일정 확률로 아군 도시 한 곳에 열리고 날이 밝으면 사라집니다.
- 장터 한정 장비, 희귀 장비 할인, 군량 암거래, 혼불 용병, 밀정의 지도, 환혼단을 팝니다.

## 개발 메모

- 외부 라이브러리 없이 순수 HTML, CSS, JavaScript와 Canvas 2D로 만들었습니다.
- 세이브 데이터 버전은 `v: 4`입니다. v3 세이브는 이어하기 때 자동으로 새 시간대로 바뀝니다.
- 디버그용으로 `window.__dbg`에 게임 상태(`G`), 전투(`Battle`), 턴 진행(`endTurn`) 같은 함수가 열려 있습니다.
- Claude(바이브코딩)로 개발 중인 프로젝트입니다.
